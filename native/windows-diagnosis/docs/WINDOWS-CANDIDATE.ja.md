## 実施順（JA・EN をそれぞれ確認）

1. 承認済み Windows 11 x64 の**標準ユーザー**で実施。候補 ZIP の SHA256SUMS を確認し、作業を保存。警告・組織ポリシーで止まった場合は「BLOCKED」として中断。保護機能や権限を変更しない。
2. JA/EN 初期表示と切り替え、800×650・100/150/200% 表示で、案内・要約・詳細の開閉・キーボード操作を確認。同意や本人回答が失われないこと。
3. 「どれを選べばいいか分からない」の案内→ファイル選択→キャンセル→ゲーム本体を選択。Steam.exe / CrashReport.exe の誤選択を拒否し、元の対象を保持すること。実在しないファイルを捏造しない。
4. ゲーム共通とワイルズで対象・症状を切り替え、ワイルズ専用取得や履歴が別ゲームへ混入しないこと。Steam の任意確認は別の同意で行う。
5. **既存の安全に観測できたログ**で実取得を確認。取得完了で一致 0 件／取得失敗・部分取得／名前のみ一致／別対象を区別すること。反映待ちや原因・解決を断定しないこと。該当する自然な失敗状態がなければ未実施のまま残す。ログ削除・権限変更・故意のクラッシュで作らない。
6. 計測中・取得中に中止。以前の受理済み結果が不完全な新データに置き換わらず、言語選択が再び使えること。既存記録の再取得は新しい試行にならないこと。
7. 非個人情報のテスト用手順記録を明示保存→アプリ終了→再起動→同じ EXE・コース・症状を選択→確認して復元。別対象では復元できないこと。DPAPI 保護は Windows 実機で確認する。
8. 履歴のゴミ箱移動を一度キャンセルし、その後にアプリ・Windows の確認を経て移動。対象はアプリ自身の履歴だけ。完全削除への切り替えはキャンセルし、ゴミ箱は空にしない。再起動後に履歴が残らないこと。
9. 共有プレビューと保存同意、既知名オプション変更時の同意解除、保存キャンセルを確認。生ログや個人情報を公開しない。PC 全体の異常を本人回答で示した場合、安全停止が詳細を閉じても残り、再現操作が無効になること。

結果は候補ハッシュ、OS/.NET バージョン、表示倍率、各 ID W01〜W12 の JA/EN 別 PASS/FAIL/BLOCKED/NOT RUN だけを記録してください。個人名、PC 名、ファイルパス、生ログ、診断内容、個人情報を含む画面を公開 repo に追加しないでください。実機スクリーンショットは作成していません。
