ゲムなお｜PCゲーム診断 0.6.0（Windows x64・試作版）

未署名・この版のWindows実機確認前です。保護機能に止められたら中止してください。
警告を回避したり、管理者実行や保護無効化で通したりしません。
原因の確定や自動修復を保証するものではありません。

言語: 上部の Language / 言語 で English / 日本語を選べます。
Windowsの日本語表示では日本語、その他は英語で起動します。選択は今回だけ。
待機中の切替で回答・同意・取得事実・履歴は消えず、再読取りも行いません。

1. ZIPをすべて展開する
   Gemnao.Diagnostics.exe と .exe.config が同じフォルダにある状態でEXEを普通に開く
   インストーラー、PowerShell、SDK、管理者実行は不要

2. 「1 準備」で選ぶ
   診断するルール: 「PCゲーム共通（通常はこちら）」
   困っている症状: 起動不可/クラッシュ/黒画面/フリーズ/低FPS/カクつき/その他
   ゲームの配布元: 分からない / Steam / Steam以外
   読み取り範囲に同意 →「自分で本体EXEを選ぶ」
   Steamならゲーム右クリック→管理→ローカルファイルを閲覧で本体の場所を確認
   ランチャーやCrashReport用とは別の場合あり。不明/保護された場所なら無理に選ばない

3. すでに症状が出たら、再現しなくてよい
   「すでに症状が出た場合: 直近10分を読む」
   新しく安全な比較をする時だけ「症状を確認する直前 → 記録開始」
   自分で起動して同じ短い場面を確認する。このツールは起動/操作をしない
   レポート生成画面があれば完了を待つ
   「症状確認・レポート生成完了後 → 読み取る」
   早く押した場合は「起動し直さず、同じ記録を読み直す」（開始から最大30分）

4. 「3 次の一手」で、未実施の手順を1つずつ
   試したら状態を「自分で試した」→「1つ試したら → 同じ場面を再テスト」
   改善した/変わらない等を本人が記録する
   すでに試して変わらない操作を繰り返さない。遊べるなら追加変更/再現は不要
   PC全体の電源断/再起動/完全停止/異常発熱がある時は再テストしない

5. 共有する場合も、まずローカル保存して内容確認
   「4 詳細と保存」→「共有する内容を確認して保存」→全文を読む
   「保存される全文を確認しました」→「ローカルにテキスト保存」
   アプリから送信しない。同期フォルダではOS等が同期する場合がある

6. 次回も手順履歴を使う時だけ保存
   「5 実施履歴と改善報告」で手順・状態・結果を選び「選択した手順と結果を記録」
   別の履歴同意 →「このPCに履歴を保存」。チェックだけでは保存しない
   次回は同じ本体・ルール・症状を選び、同意→「保存した履歴を読む」→内容確認
   別の本体/場所/症状の履歴や0.4以前の履歴は読まない。過去の観測は比較元にしない

追加確認は任意
・Steam選択時だけ、実際のsteam.exeを手動選択して固定名の追加確認へ同意できる
・Wildsは「Monster Hunter Wilds Steam版の固有ルール」を本人が選ぶ
  MonsterHunterWilds.exeだけ対象。検索・痕跡・CrashReport解析が追加で使える
  一般ゲームのZIP/ダンプは読み込まない
・一般ゲームの改善報告JSONは未対応。Web受付は準備中。保存＝送信ではない

限界
FPS/フレーム時間/温度を測定しません。低FPS/カクつきは本人の同条件比較です。
ゲーム固有の全障害、通信/音声/入力/アカウント問題、ハード故障は診断しきれません。
Windows11 x64 / .NET Framework4.8以降用。ARM/32-bit/Windows10実機確認は未実施です。

削除
保存履歴を消す: アプリ内「保存履歴をゴミ箱へ」→Windows確認
完全削除の警告なら取り消す。画面内履歴は別なので終了/新しい診断でクリア
履歴場所: %LOCALAPPDATA%\Gemnao\GameDiagnosis\history-v2.dat（処理中は.tmpも）
アプリ削除: 終了して展開フォルダ/ZIPをゴミ箱へ。別保存の履歴/TXT/JSONは残る
