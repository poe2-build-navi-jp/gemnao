# 非公開診断の通知：レビュー用候補

メール通知は初期OFF。アプリにもメール送信サービスにも接続していません。

`ops/private-diagnostic-review/relay-policy.mjs` は固定通知の方針だけを実装します。有効化値は既定falseで、literal trueのみ許可します。受け入れる入力は新規保存が確定したという種類だけです。本文、個人情報、受付ID、任意宛先などの追加項目を拒否します。

メールは固定件名と「新しい診断結果が届いた」の一文だけです。URL、診断内容、識別子、個人アドレスを含みません。送信サービスによる受付、拒否、結果不明、未設定を区別し、生の応答やエラーを返しません。自動再試行はしません。送信サービスによる受付はメール到着やチャット通知の成功を意味しません。

将来の接続では、新規保存だけが通知を発生させること、再送時の重複を防ぐこと、送信失敗と診断保存成功を分離することが必要です。通知用の記録も最大30日を超えて保持せず、診断原文や個人情報を複製しません。送信結果が不明な場合の照合・再試行方針を確定するまで自動再送は有効化しません。

送信元ドメインの所有、送信先の本人確認、宛先を限定する送信設定、無料枠、通知先への合成データによる到達確認が未完了です。実設定は個別の確認・承認後に行います。秘密や設定値をこの文書や公開repoへ記録しません。メール配送やイベント処理には遅延・失敗があり、即時通知やexactly-onceを保証しません。
