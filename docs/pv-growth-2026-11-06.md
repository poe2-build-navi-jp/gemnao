# 検索流入と再訪の改善（2026-11-06）

## 実施した5項目

1. Search Consoleの直近28日・ページ別と検索語の実績を確認。アニモの検索タイトル・descriptionと冒頭の症状別入口を改善。11〜30位の候補だったDiscordサーバー募集には参加後に遊ぶまでの案内と音声トラブルへの導線を追加。元の実績データは公開リポジトリに含めない。今後の選定用CSVツールは `scripts/gsc-opportunities.py`（使い方は `docs/gsc-opportunities.md`）。
2. Steamの「実行ファイルが見つかりません」「アプリはすでに実行されています」を、症状別の見出しと最初の確認・次の行き先で補強。PCクラッシュも発生タイミングから本文へ移動できる。既存URLを維持して重複記事を増やさない。
3. Enshrouded 1.0.1.2（11/4）と1.0.1.0（11/2）、Planet Zoo 2 1.0.9（11/5）の一次資料を確認。対象条件・公式修正の範囲・残る場合の次の行動を日付と出典付きで記事へ掲載。同じ記録をマイゲームにも表示。新しいカードはja/en/zh/esで掲載。
4. Wildsの既存本人報告を、該当ゲームハブとSteam起動・PCクラッシュの共通ガイドからも読めるようにした。比較に必要な環境と結果、本人報告1件・独立再現なしという範囲を表示。公式の修正告知も実機成功例とは区別する。新たな架空の体験談・投票は追加しない。
5. 日本語・英語・中国語・スペイン語のトップとマイゲームに保存ゲームの未読更新一覧を追加。登録ゲームだけを抽出し、更新日順に最大3件を掲載。全件確認への入口を設ける。初回は以前の告知も未読になることを明記。既存の既読キーを使い、ページ閲覧だけでは既読にしない。ノート・診断結果・ゲーム選択は書き換えない。
