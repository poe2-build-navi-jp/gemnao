# 解決データ画像：次段階の実装条件

今回の10点は記事のSTEP名から作った静的図解であり、D1の解決報告数・解決率は含めない。現行D1は記事・トピック別の回答総数とSTEP別解決回答の集約値を持つ。画像に件数を入れる場合は、対象記事の回答10件以上、STEP IDと回答の整合、生成時点の表示を検証し、画像のURLと更新時刻を管理する。件数は「人」ではなく「解決回答」と表記し、未解決回答や重複回答の可能性もHTML本文に説明する。

集約値の `updated_at` は直近の更新時刻で、過去7日間の時系列ではない。期間ランキングや、D1にない画像内数値を生成しない。画像を生成するまでは本文の既存の実データ表示を利用する。
