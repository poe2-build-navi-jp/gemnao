# 解決データ画像：実装と公開条件

既存の10点は記事のSTEP名から作った静的図解であり、D1の件数を含めない。別途 `/api/solution-image?game=<記事コンテキスト>` がリクエスト時にD1の回答集計からSVG画像を生成する。STEPのIDは公開記事の定義と照合し、ラベルも記事本文の値を使う。回答総数10件以上かつ整合するSTEP別の解決回答10件以上でだけ画像を表示する。条件を満たさなければ404を返し、記事は既存の集計中表示を維持する。画像を表示する記事では、D1の新しい回答も再読み込み時に反映される。

画像には生成時点（UTC）、解決回答・全回答の件数、STEPごとの件数を記し、「人」ではなく「回答」と表記する。自己申告・重複報告の可能性は画像とHTML本文に記す。集約値の `updated_at` は直近の更新時刻で、過去7日間の時系列ではない。期間ランキングや、D1にない画像内数値は生成しない。画像と集計APIには `Cache-Control: no-store` を付ける。実データが閾値に達するまでは公開記事に数値入り画像は表示されない。
