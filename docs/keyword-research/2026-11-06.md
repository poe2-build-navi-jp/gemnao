## Implemented selection

- Highest measured phrase, `steam クラウド`: `/guide/steam-cloud-basics` explains support, settings, file locations and migration preparation. Keeps the existing sync-error guide for troubleshooting intent.
- Second, `steam 起動しない`: `/guide/steam-client-not-opening` distinguishes the Windows Steam client from a single game that will not launch. Existing game troubleshooting links to this entry.
- Third, `steam セーブデータ バックアップ`: interactive readiness checklist on the existing `/guide/save-data-backup`, rather than another competing page. Conflict/missing-save selections prioritize preservation. Five selected confirmations are not proof of file integrity or a successful restore.
- New articles and checklist available in Japanese, English, Chinese and Spanish; demand figures are Japanese only. Existing index policy is unchanged: Japanese and English in sitemap/hreflang; Chinese and Spanish remain published with the existing noindex policy. Home and symptom hubs expose the new articles. Existing routes retained.
